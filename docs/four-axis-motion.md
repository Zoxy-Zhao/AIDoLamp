# 四关节机械臂与独立夹爪

当前项目使用四个运动关节（底座、肩、肘、腕）加一个夹爪通道，共五个执行通道。夹爪开合不增加末端位置/姿态的运动自由度，因此 FK/IK 输入始终是四个角度。

## 几何与任务

`src/motion4dof/model.py` 是 `ObjectTracker` 和离线演示共用的几何模型。默认长度为 8/24/24/8 cm，单位为 cm、degree。软件示例限位分别为 [-135,135]、[-90,90]、[0,150]、[-90,40] 度，可通过 `Arm4` 构造参数调整；实物零位/正负方向仍须与 PCA9685 映射核对。

基座绕 Z 转动，肩、肘、腕在同一竖直平面内运动。采用现有连杆角约定：前臂俯仰为 shoulder - elbow，工具俯仰为 shoulder - elbow + wrist。FK 逐连杆累加实际位置，不使用请求的目标点替换计算端点。

IK 将工具偏置从目标 TCP 中扣除，用余弦定理解肩肘，再由指定俯仰求腕角；枚举前后基座方向和肘部解，限位过滤、FK 复核后按种子关节距离选解。四关节仅支持本构型可实现的位置与俯仰约束，不能任意指定完整六维姿态。不再通过裁剪关节角把不可达请求伪装成成功。

- 人脸：固定肩 60°、肘 30°，解基座与带符号的腕角，使光轴指向目标。过近或越限目标被拒绝。
- 书本：按目标构造上方照射 TCP，求四关节协调解。默认照射距离为 **30 cm 软件样例**，可配置；较大距离可能因腕限位不可达，明确拒绝。
- 夹爪：独立 `GRIP` 指令；演示的 20°/80° 为示例开合指令，不是抓取力度、开口毫米值或夹持成功证据。

## 轨迹与通信

`trajectory` 使用五次多项式 10u³−15u⁴+6u⁵，默认最大关节速度 60°/s，必要时延长时长。起止速度、加速度为零；上位机统一调用这一实现，不再仅在展示程序中使用平滑曲线。整数指令与浮点规划角分开记录。

`SerialCommunicator.send_servos_smooth` 预检全部目标与指令，按单调时钟发送；运动锁避免多条轨迹/夹爪操作交错，发送锁保护串口帧。短写或串口失败锁存故障并停止后续指令，已发送角仅为指令估计，不是到位反馈。重新接入设备前需人工同步实际位置。

| 指令 | 参数 | STM32 执行通道 |
|---|---|---|
| `Alldro q0 q1 q2 q3\n` | 恰好四个有限角度，满足四关节限位 | PCA9685 0–3 |
| `GRIP angle\n` | 恰好一个有限角度，默认 0–180° | PCA9685 4（可配置） |

`send_gripper(angle)` 为上位机入口；`contact.c` 调用 `lamp_motion.h` 中的实际运动分发函数。所有参数验证完成后才调用 PWM 驱动，不允许缺参、超参、NaN、无穷、越限导致部分通道先动作。夹爪通道不能与 0–3 重叠；宏 `LAMP_GRIPPER_CHANNEL/MIN/MAX` 配置接收范围。现有角度零位宏位于 `PCA9685.h`。

夹爪配置包括接线、行程与安全开合角。发送端需使用支持 `GRIP` 的匹配接收端。UART DMA/主循环接收框架采用单缓冲区，分片、突发流量与板端时延需另行验证；主机 C 测试针对完整帧运动处理函数，不代表 DMA 收包或真机执行测试。

## 软件测试与展示

```bash
python -m pip install -r software-requirements.txt
python -m unittest discover -s tests -v
python -m src.motion4dof
python -m src.motion4dof --fault unreachable --output output/unreachable.json
python -m src.motion4dof --fault transport --output output/transport.json
python -m src.motion4dof --fault estop --output output/estop.json
```

测试环境：Python 3.12.4 / NumPy 1.26.4 / GCC 8.1.0：**24 项全部通过，无跳过**。其中四关节 10 项、独立六轴补充算法 14 项。四关节覆盖 300 组随机位姿往返、已知 FK、目标瞄准、不可达、轨迹限速、四关节/夹爪隔离、串口失败及 C/Python 指令一致性。

正常演示生成 **125 个样本、126 帧指令**；不可达场景零下发，模拟串口故障/急停冻结后续动作，正常退出码 0、故障退出码 2。HTML 支持机械臂姿态回放，JSON 保存合成输入、示例几何、整数指令角、TCP、虚拟时间与角度量化差值。

不把软件验证写成真实照射精度、无碰撞或夹爪抓取成绩。演示不运行摄像头、YOLO、MediaPipe、物理串口或 PWM。控制程序的任务调度仍包含阻塞等待，推理时延不能代替整机追踪周期。
