# 台灯控制、视觉与调度

当前控制配置是四个运动关节加独立夹爪，共五个执行通道。运动模型、串口帧和实际测试见 [四关节说明](four-axis-motion.md)。夹爪不计入定位自由度。

## 主程序链路

`main.py` 通过 `ObjectTracker.track_face/track_book` 调用共用四关节模型，返回弧度；转换成度后调用 `SerialCommunicator.send_servos_smooth`，执行统一五次插值并发送四角度 `Alldro` 指令。`send_gripper` 独立发送 `GRIP`，并与运动共用发送锁和运动锁。固件 `contact.c` 先调用 `lamp_motion` 验证完整参数，分别驱动 0–3 与 4 通道。

人脸固定肩/肘为 60°/30°，求基座和带符号的腕角；书本按工作距离构造照射位置和工具俯仰。FK 始终从关节角计算真实模型末端，不用请求目标替代 FK 端点。不可达或越限目标抛出异常，主程序不发送该动作。

## 感知与模式

| 模块 | 入口 | 内容 |
|---|---|---|
| 目标检测 | `src/yolo_class.py` | YOLO 人脸/书本检测，目标坐标估计 |
| 手势识别 | `src/gesture_class.py` | MediaPipe 关键点与分类器 |
| 联合感知 | `src/csi1.py` | 手势与坐姿任务 |
| 模式调度 | `src/main.py` | 待机、普通、互动、写作与工作线程 |
| 语音交互 | `src/voice_class.py` | ASR/TTS 与对话服务 |
| ONNX 实验 | `training/yolo/identify_pi/main_onnx_pi.py` | YOLO 的 ONNX Runtime 推理 |

双 CSI 摄像头承担不同任务，不表示已实现双目立体测距。目标坐标包含视场角、物体尺寸或距离输入估计，需实物标定才能验证基座坐标精度。ONNX 实验不表示主程序或手势分类器已切换该后端。

## 部署边界

软件测试覆盖几何、通信接口和主机执行。运动状态保存的是发送角度；模式切换包含固件初始化动作，切换或重新上电后必须核对实际位姿。跟踪线程仍包含阻塞轨迹调用和等待，不将推理时延作为跟踪周期。夹爪动作由显式 API 控制，接入手势或语音需另行设计确认流程。
